# Entre Viñetas — Tienda de cómics

**Miguel Ángel Ossa**  
Programación Orientada a la Web · Universidad Santiago de Cali

Aplicación web para consultar y registrar autores y cómics. Utiliza HTML, CSS y JavaScript en el cliente, una API REST con Node.js y Express, y persistencia documental en MongoDB Atlas.

## Funcionalidades

- Catálogo de cómics con búsqueda por título y filtros por autor y editorial.
- Listado y registro de autores.
- Registro de cómics asociados a un autor.
- Validación de datos y mensajes de respuesta.
- Diseño adaptable a dispositivos móviles.
